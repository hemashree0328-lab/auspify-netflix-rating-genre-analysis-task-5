# Auspify Task 5: Content Rating & Genre Analysis

## 📌 Project Overview
This project analyzes Netflix content ratings and genres using Python to explore audience-suitability categories and genre distributions across Movies and TV Shows.

## 🎯 Objectives
- Analyze Netflix content rating categories.
- Identify the most frequently represented genres.
- Compare ratings across Movies and TV Shows.
- Create visualizations to communicate findings.
- Generate data-driven business insights.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
